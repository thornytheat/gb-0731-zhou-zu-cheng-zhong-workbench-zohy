# 称重数据定义

| 文件 | 业务键与必填字段 | 单位与时间 |
|---|---|---|
| `*-triggers.csv` | 全批记录号、车次、轮道、采样时间、载荷、单位、质态。备注可空 | 轮道 L/R，质态 OK 才采信。载荷支持 kg、千克、斤、t |
| `passes.csv` | 文本车次键、车牌、入口、出口、速度米每秒 | 入口包含、出口排除。速度 0.5–40 m/s |
| `certificates.csv` | 证书号、轮道、生效、失效、增益、偏置千克 | 左闭右开，增益 0.1–10，偏置 −500–500 kg |
| `*-tickets.csv` | 磅单号、车次、版次、车牌、签发时间、总重、单位 | 版次正整数字串，签发在入口至出口后 15 分钟的半开区间 |

所有数字以 Decimal 解析和计算。斤乘 0.5，吨乘 1000。修正轮载为原始千克乘增益加偏置，四舍五入到 0.01 kg 后校验范围 `(0, 25000]`。空串和 `-`、`N/A`、`NULL`、`未知` 在必填字段里视为缺值。时间接受带偏移的 ISO 8601，后端统一 UTC，页面显示 UTC+08:00。前导零按源记录保留。

## 去抖与轴组

1. 同记录号以车次、轮道、UTC 时刻和精确原始千克比较。等值重送留最小来源行。不等值时，对仍可用的记录附冲突证据并隔离。先前阶段已隔离的行保持原原因码。
2. 同车次同轮道按 UTC 时刻和源行排序。距上次保留触发不超过 12 ms 计作回弹，回弹不更新去抖锚点。
3. 对侧 35 ms 内须双向唯一。候选缺失或歧义单列；轴时刻为两轮时刻中点。对相邻独立车轴用间隔和速度推轴距，允许 `[0.55, 12]` m，异常距离涉及的两轴都隔离。有未配对触发夹在候选轴之间时，重启轴组计算，不穿过缺证区间推距。
4. 合格相邻轴距在 `[0.55, 1.80]` m 时属于同组，距离更大或中间有证据缺口时新开一组。
5. `abs(左轮重−右轮重) / (左轮重+右轮重)` 达 10% 判偏载，达 20% 判严重。先比较精确比例，再把展示百分比四舍五入至两位。

## 静态磅单与复核

同车次选最高版次。最高版次同值重送保留最早源行并列出等值证据。冲突时挂账，车次含坏磅单时保守地阻止采信。车牌或签发时间不匹配时留空差额。整车差额绝对值超过 50.00 kg、缺磅单、缺轮载证据或没有确认车轴时，状态为待复秤。偏载判级与整车总重勾稽分别用于轴载稽核和总量核验。

## 批次与归档

批次键包括样例选择、四份文件的 SHA-256、规则版本和参数。结果用 Decimal 字符串、文本键和 ISO 时间序列化。提交事务同时写归档和触发日志。重跑重新计算并比对序列化内容，匹配后仅追加验证事件。源文件变化返回 `SOURCE_CHANGED`，已归档批次仍可查看并下载。

复核包含运行清单、触发复核、轴组轮载和整车勾稽。`源文件行` 以实物 CSV 行号定位，多行备注保留起止行和原值。事件 `time` 为处理时间，`source_time` 是与事件关联的轴时刻。批次查询返回最近 50 条归档，日志用事件序号向后翻页。
